🚀 QUICK START (2 MINUTES)
─────────────────────────────────────────────────────────────────────────────

1. CLICK Profile Button
   Location: Top-right of popup (👤 icon)

2. CREATE New Profile
   • Type name: "My Settings"
   • Click [+ Create Profile]

3. CONFIGURE Settings
   • Click on your new profile
   • Toggle settings as needed
   • Click [💾 Save Changes]

4. LOAD Profile
   • Click [✓ Load Profile]
   • ✓ Settings now active!

📊 PROFILE STRUCTURE
─────────────────────────────────────────────────────────────────────────────

Each profile contains:
  
  {
    id: "1234567890",              ← Unique identifier
    name: "Profile Name",          ← User-defined name
    createdAt: "2026-05-27T...",  ← Creation timestamp
    updatedAt: "2026-05-27T...",  ← Last modified
    settings: {
      closerHelperEnabled: true,   ← Closer Helper On/Off
      autoExport: false,           ← Auto Export On/Off
      autoExportFormat: "xls",     ← Export format
      theme: "light"               ← Theme preference
    }
  }

🎯 COMMON WORKFLOWS
─────────────────────────────────────────────────────────────────────────────

CREATE PROFILE (2 minutes):
  1. Click 👤 Profile button
  2. Type name → Create
  3. Click profile → configure
  4. Save → Load
  ✓ Done!

SWITCH BETWEEN PROFILES (10 seconds):
  1. Click 👤 Profile button
  2. Click desired profile
  3. Click [Load]
  ✓ Settings switched!

BACKUP PROFILES (1 minute):
  1. Open Profile Manager
  2. Click profile → Export
  3. Save JSON file
  ✓ Backup complete!

SHARE WITH TEAM (2 minutes):
  1. Export profile to JSON
  2. Share the file
  3. Team imports it
  ✓ Everyone synchronized!
